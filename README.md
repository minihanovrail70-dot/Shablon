# Приглашение на свадьбу — Александр и Анна

Файлы:
- index.html — структура приглашения
- style.css — дизайн
- script.js — анимации, фон, обратный отсчёт, музыка и форма
- Fon.mp4 — фоновая драпировка
- music.mp3 — мелодия, которая играет после открытия приглашения (нужно добавить самостоятельно)

Запуск:
1. Положите все файлы, включая выбранный вами music.mp3, в одну папку.
2. Откройте index.html в браузере.

О музыке:
Мелодия начинает играть, когда гость нажимает «Открыть приглашение»
(браузеры не разрешают автозапуск звука без действия пользователя).
Справа сбоку экрана появляется полупрозрачная кнопка-регулятор — ею можно
включить и выключить звук в любой момент. Просто замените music.mp3 на
любой понравившийся трек с таким же именем файла — код менять не нужно.

Карта:
В блоке «Место» кнопка «Открыть карту» ведёт на Яндекс.Карты с запросом
«Правда Холл, Уфа». Если у вас есть точный адрес или ссылка на
организацию в Яндекс.Картах, лучше подставить прямую ссылку — так карта
откроется точно на нужной точке, а не по текстовому поиску.

Дата свадьбы обновлена на 26.09.2026 везде (заголовок, экран приветствия,
обратный отсчёт, подвал).

Для публикации можно загрузить папку в GitHub и подключить Cloudflare Pages.
Форма RSVP сейчас демонстрационная: она показывает подтверждение на странице,
но не отправляет данные на сервер.
